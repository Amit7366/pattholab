# Pattho client

Next.js App Router frontend with TypeScript and Tailwind CSS.

## Scripts

```bash
npm install
npm run dev
```

The app runs at `http://localhost:3000` and talks to the API at `NEXT_PUBLIC_API_URL` (see `.env.example`).

## Screens

- `/` — product intro and the built-in roles
- `/register` — public student registration
- `/login` — sign in for every role
- `/dashboard` — role workspace, plus user and role tools when the account has permission
